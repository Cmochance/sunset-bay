Sunset Bay is a sun-soaked open-world crime game: explore a living city on foot and by car, steal cars, outrun the Bay PD at up to five wanted stars, fight, and run five story missions for fixer Mara Voss — from a first stolen car to a harbour heist. Built with vanilla JavaScript on a 2D canvas, fully offline.

## Run it

```sh
node serve.ts  # then open http://localhost:8080
```
